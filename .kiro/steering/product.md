# Product Overview: Kiroman

## Description
A cute, Kiro-branded twist on Pac-Man where you run from Kiro and climb a global leaderboard.

## Abstract
Kiroman is a cute, Kiro-branded twist on the classic Pac-Man arcade game. Players enter an alias, run from Kiro through a maze collecting pellets, and compete on a global top-three leaderboard of the highest levels reached. It plays on both desktop web and mobile and is deployed to AWS as a serverless app.

## Target Users
Kiro fans and casual arcade players on web and mobile
